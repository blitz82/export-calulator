# 가져오기와 증빙

범용 생산자 입고 CSV의 열 매핑·미리보기·선택 등록·원본 추적·재제출 이력은 [입고 CSV 명세](INTAKE_CSV_IMPORT.md)를 참조한다. 기존 선별 Excel과 별도 경로이며 특정 ERP 전용 연동으로 표시하지 않는다.

페이지 체크포인트·추출 해시·로컬 대조 기록·PDF/Excel 비교 API는 [PDF 페이지 검토](PDF_PAGE_REVIEW.md)에 명세한다.

표준 Excel은 검토 화면에서 내려받는다. 표준·공동선별 세부내역·수출실적 리스트의 머리글 후보를 탐색한다. 업체명·행번호로 분기하지 않는다. 파일 20MB, 압축 해제 180MB, 5,000 ZIP 항목, 50,000행, 128열 제한이다. 매크로는 미리보기에서 거절하며 수식을 실행하지 않는다. 수식 원문은 보존하고 물량·날짜 등 필수값의 수식은 자동 등록하지 않는다. 참고·조정·집계 시트는 합산하지 않는다.

증빙 업로드→시트 선택→원본 행 미리보기→행 선택→시설·품목 확인→작업으로 등록한다. 미리보기는 작업/신청을 쓰지 않는다. 선택 행 등록은 한 transaction이며 실패 시 전체 rollback한다. 같은 hash·시트·원본 행은 재등록하지 않는다. 가져온 신고번호는 후보이며 실제 품목란 매칭과 물량 예약은 별도이다. 원본 시트·행·셀·원문·매핑버전은 작업 data.source에 보존한다.

사용자 제공 Excel 2개는 각각 합계행 제외 112행·126,524kg을 확인했다. 원본에는 수식 합계행이 있어 단순 수치 합산은 두 배 집계를 유발한다. 합계 문자열 공백을 정규화해 제외한다. 다른 사례의 세부 PDF는 주로 스캔이며 51건·비용·이체 전수 대사를 완료했다고 주장하지 않는다. HWP 2개는 인벤토리만 확인했으며 본문 자동 해석은 미구현이다.

PDF는 기존 epms.ocr를 변경하지 않고 새 어댑터가 최대 150쪽을 30쪽씩 처리한다. 완료 청크는 증빙 ID·hash·OCR 버전으로 DB에 저장되어 재시도 시 재사용한다. 신고/운송/기타 쪽 분류, 신고번호·품목란·개정 후보 묶음, 충돌 및 원본 좌표를 보존한다. AWB/B/L은 연결 후보이며 gross weight를 순중량으로 사용하지 않는다. 재발급·갑을지의 중량을 합산하지 않는다. OCR 자동 승인·외부 OCR 서비스는 없다. 실제 혼합 스캔 정확도·모든 회전·문서 누락 조합 및 강제 종료 복구의 현장시험은 남아 있다.

S6의 문서 PDF는 1쪽 스캔이며 인쇄 쪽번호 27을 확인했다. SHA-256은 9720b300779ec549d642ab77326fc82f99e33e69a549448a93b905769688e6f4, S7 2026-09-01 서식은 abaadffc754ef4b4ba734b4c48be8fb46caf50dac04b072b7d370b05acc426b3이다. 시행일은 별도 근거 미확보로 null이다. 전체 첨부 6종 목록을 임의 구성하지 않는다. 해시는 동일성 검사이며 전자서명 또는 법적 진본보증이 아니다.

자료 대사 화면은 두 evidence 원본의 hash를 다시 확인한 후 시트별 원문을 읽기 전용으로 비교한다. 파일 hash·시트·원본 행/셀·신고번호 원문·수량과 비교 hash를 보존한다. 동일 번호가 복수이거나 품목란이 없으면 자동 물리 매칭을 하지 않는다. 수식/공란은 UNKNOWN이며 실제 0과 구분한다. CSV는 텍스트 접두로 식별자/정밀도와 수식 주입 방지를 보장하는 검토 출력이다. 실제 두 파일의 112건 수량 일치와 PDF/HWP 검증 공백은 SAMPLE_RECONCILIATION_REPORT.md에 기록했다.

인쇄용 서식은 sorting_print.py의 코드 기반 HTML/CSS이며 오프라인 Edge/WebView 브라우저 인쇄를 사용한다. 기존 openpyxl Excel 엔진을 교체하거나 런타임 의존성을 추가하지 않았다. A4 3쪽 검토 초안의 PDF 렌더링을 시각 확인했다. 실제 공식 서식 인수가 아니라 2026.9.1 항목을 참조한 2027 검토용이며 확인되지 않은 A~F/G와 신청업체를 생성하지 않는다.
