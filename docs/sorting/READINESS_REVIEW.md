# 지급 준비 종합 점검

2026-11-23 최신 보완: 서면 업무방식의 인증·직무분리·은행·기관 예산·자격 심사는 OUTSIDE_SYSTEM(기관 외부 절차)으로 분류한다. 프로그램 내부 필수 구축 과제가 아니다. 로컬 기록은 은행/서명 검증이나 적격 판정이 아니다. 상세는 [PAPER_WORKFLOW.md](PAPER_WORKFLOW.md), 최신 검증은 IMPLEMENTATION_STATUS.md를 따른다.

2026-11-23. 선택 신청의 현재 원장·귀속·고정 명세·지급 준비를 한 화면에서 대조하는 **읽기 전용** 점검이다. 지급 가능/적격 여부를 결정하거나 운영 승인·실제 지급 상태를 생성하지 않는다.

## 사용법

1. 상단에서 신청을 선택하고 ‘검토자료 보관 → 지급 준비 종합 점검’을 연다.
2. 비교할 명세와 지급 준비 대장을 선택한다. 준비 대장만 선택하면 그 대장의 기준 명세를 사용한다. 명세를 별도로 지정해 다른 기준을 선택하면 불일치를 표시하며 임의로 합치지 않는다. 아무것도 선택하지 않았는데 보존 자료가 있으면 ‘미선택’으로 안내하고, 실제 보존 자료가 없는 경우와 구분한다.
3. ‘자료 보완 / 원본 재검토 / 정책 판단 보류 / 운영 조건 미충족’ 네 영역을 확인한다. 항목 수는 확인 사항 수이며 지원 건수·미비 서류 수·진척률이 아니다.
4. ‘○○에서 확인’으로 관련 화면에 이동한다. 신청 행은 해당 필터·페이지·행으로 이동하고 계약/이행 입력 또는 원본 비교를 펼친다. 선택 명세와 준비 대장은 해당 ID로 연다. 준비 편집을 이미 같은 ID로 진행 중이면 편집을 유지한다. 다른 대장으로 명시적으로 이동하면 그 대장을 선택한다.
5. 보완 기록을 저장한 뒤 돌아와 ‘종합 점검 다시 조회’로 현재 원장을 대조한다. 탭 이동 중 대조 대상 선택은 유지하지만 새로고침·신청 변경 시 영구 저장하지 않는다.

## 점검 범위

| 영역 | 표시하는 내용 |
| --- | --- |
| 자료 보완 | 이행/확인서 등 신청 검토 항목, 계약 연결, 회원 귀속/미귀속 물량·비용, 비용 배부 유무, 명세·준비 선택, 회원별 준비액/예정일/서류목록/근거 누락 |
| 원본 재검토 | 신고·증빙 변경, 계약 개정, 현재 신고 순중량과 로컬 전체 활성 예약의 초과, 귀속 기준 변경, 명세·준비 기준 불일치, 취소/종료, 비용·이체 원본 무결성, 조회 불가 |
| 정책 판단 보류 | 시설 지정기간/귀속월 관련 정책 쟁점 및 P-01~15 확정 정책·실제 정책 승인 어댑터 부재 |
| 운영 조건 미충족 | 외부 중복원장, 독립 인증/직무분리, 운영 예산·지급 전 점유, 실제 은행/보조금 지급 원장, 농가 정산·수혜 자격의 별도 전수 심사 |

비용 대사는 선택 신청에 활성 배부된 비용만 표시하고 관련 없는 다른 비용을 이 신청의 검사 결과로 섞지 않는다. 비용 미배부는 비용 0원으로 해석하지 않는다. 정상 이체 후보와 실제 은행 확인을 구분한다. 신고 물량 초과는 현재 로컬 DB의 같은 물리 신고키 활성 예약 합계와 비교하며 자동 예약 조정·해제·환수를 수행하지 않는다.

‘로컬 기록 확인’은 저장/연결/산술 비교 사실만 표시한다. 계약 동등성·생산자 동일성·실제 수출이행 인증·최종 비용 적격·정책·예산 승인을 의미하지 않는다. 준비 입력이 완료되어도 정책/운영 미확인 항목은 계속 표시한다. API의 payment_eligible=false는 이 설치에서 운영 지급을 허용하지 않는다는 뜻이며 개별 신청의 법적 부적격 판단이 아니다.

## 읽기 전용과 오류 처리

GET /api/org/{org}/sorting/claims/{claim}/readiness는 단일 SQLite 읽기 transaction에서 대조한다. 신청·배분·비용·귀속·명세·준비·감사 기록을 추가/변경하지 않는다. 새로운 완료/승인 플래그를 저장하지 않으며 승인액·지급액은 null이다.

독립 자료의 무결성 오류/확인 불가는 재검토 항목으로 표시한다. 요청 자체가 실패하면 결과 영역을 숨기고 오류와 재조회/선택 초기화를 제공한다. 로딩·공란·조회 실패를 ‘문제 없음’으로 표시하지 않는다. 잘못된 조직/신청/명세/준비 ID는 범위 검사로 거절한다.

이 화면은 전체 필수 첨부 목록, 실제 현장 물량, 기관 권한, 실제 은행, 다른 PC/DB/타 사업 원장의 전수 검증을 대신하지 않는다. 운영 조건 항목의 이동 버튼은 관련 검토 화면을 여는 것이며 미구축 기능을 켜거나 운영 조건을 충족시키는 버튼이 아니다. 기존 직접·간접실적 기능과 공동선별비의 승인/지급/official 출력 차단은 유지한다.
