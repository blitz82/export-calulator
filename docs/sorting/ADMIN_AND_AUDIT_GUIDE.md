# 공동선별비 관리자와 감사 안내

로컬 세션 토큰과 x-epms-actor 표기는 사용자 인증·전자결재·직무분리를 보장하지 않는다. 관리자·배치·재시도 또는 환경변수로 운영승인을 열 수 없다. 신규 서비스의 operation_guard는 정책과 독립 승인통제가 없는 이 버전에서 항상 거절한다. 기존 EPMS 공식 수출실적 제출 기능에는 이 가드를 전파하지 않는다.

P-01~15는 POLICY_PENDING이며 2026 참조는 REFERENCE_ONLY, 2027 초안은 SIMULATION_ONLY이다. 시행일·공통 보조율·절사·2027 단가는 null이다. 테스트 산식은 TEST scope에서만 실행하며 운영 정책으로 승격하는 API는 없다. 조사·심의 중 제재를 차감하지 않는다. 확정 처분도 자동 확대 적용하지 않는다.

DB의 sorting_ 테이블과 기존 audit_logs를 함께 확인한다. 신청 원본 snapshot은 신고 ID·revision·원문 hash, 작업 버전·증빙 hash와 정책 상태를 보존한다. 신고 정정 또는 증빙 변조는 재조회 시 보완으로 표시한다. 과거 snapshot은 갱신하지 않는다. 신청·행 상태 전이는 이유와 이전·이후 상태를 기록한다. 기록 개정은 이전 ID를 참조하는 새 행이다.

과거 비용 이체증빙은 비용 적격 검토 자료이며 신규 보조금 지급 결과가 아니다. 실패·취소와 정상·재이체를 구분하고 원 거래번호 중복과 비용 원금·배부 pool 초과를 차단한다. 농가 공제액·실정산금·정부지원금과 환류액은 분리하며 후자는 미확정이다.

설정의 기존 DB backup API는 SQLite 온라인 백업을 사용하고 DB에 포함된 원본 바이트도 보존한다. 변경 전 백업을 별도 경로에 보관하고 프로그램 종료 후 사본으로 복원 검증한다. 신규 데이터가 있는 DB는 강제 downgrade하지 않는다. 운영 DB 이관은 별도 승인 후 수행한다. 로컬 관리자의 DB 직접 수정·독립 인증 부재·중앙 중복대사 부재는 통제 한계이며 해시만으로 해결되지 않는다.

sample2와 output/sorting-private는 ignore 대상으로 원본 및 개인정보를 공개 저장소·배포본·로그에 포함하지 않는다. 실제 운영 전 접근권한·보존/파기·외부원장 이용근거와 기관 개인정보 검토가 필요하다. 신규 외부 의존성과 외부 네트워크 서비스는 추가하지 않았다.

행별 이행·확인서 연결은 sorting_records의 LINE_EVIDENCE_REVIEW에 append-only로 저장한다. 최신 연결을 철회해도 과거 입력·근거 hash·표기자·사유·시각은 남는다. 조회는 입력/증빙 hash와 원장/작업/시설 snapshot, 확인서 개정 여부를 대조한다. 같은 원본 파일의 확인물량 pool을 다른 ID로 복제하거나 늘릴 수 없도록 보수적으로 제한한다. 서로 다른 확인서가 한 파일에 포함된 경우 개별 원본과 범위 확인이 필요하다.

이행 검토값이 채워지고 확인서가 대사되어도 identity_assurance=LOCAL_UNVERIFIED이다. 프로그램이 실제 발급자의 권한·서명 또는 검토자의 독립 직무를 인증했다는 뜻이 아니다. 모든 연결이 완료된 신청도 승인액/지급액은 null이며 운영 시도는 거절된다. source data 자체를 직접 편집할 수 있는 로컬 관리자에 대한 법적 진본보증으로 해석하지 않는다.
