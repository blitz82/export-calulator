## 지급 준비 검토 대장 빌드 (2026-11-23)

확정 정책/인증 없이 가능한 검토용 준비 기능을 추가했다. 보존된 회원 명세를 기준으로 고정 회원·귀속량에 수동 준비액·준비 예정일·서류목록 로컬 검토·근거를 기록한다. 준비 작성/보완/입력 검토 완료(미승인)/취소만 지원한다. 기준 명세의 정책·수출이행·확인서·외부원장 보완은 화면/인쇄에 계속 표시하며 입력 완료로 해결하지 않는다. 준비 취소는 원 신청 물량·비용 예약과 claim revision을 변경하지 않는다.

PAYMENT_PREPARATION_REVIEW 종류의 append-only sorting_records를 사용하며 신규 테이블/migration/의존성이 없다. 기준 명세 원문과 최초 신청 버전을 고정하고, 한 신청의 활성 준비 대장은 하나만 허용한다. BEGIN IMMEDIATE·대장 revision·요청키로 동시 생성/개정/재전송을 검사한다. ## 회원 귀속·지급명세 검토 빌드 (2026-11-23)

지급명세 설계의 1~2단계에 해당하는 검토 전용 기능을 구현했다. 기존 신청 배분행에 회원별 물량·원물/LOT 참조·귀속 증빙·판단 근거와 복수 비용을 연결하고, 전체 목록의 새 버전을 보존한다. 회원/시설/신고 품목란별 소계와 선택 대상 합계, 비용 귀속월·증빙, 미귀속 내역을 Excel 및 A4 가로 인쇄/PDF 저장으로 제공한다. 단일/복수 신고·작업·시설 및 복수 회원 분할을 지원한다. 회원 전용본에는 다른 회원과 전체 잔량/비용 pool 내역을 제외한다.

BENEFICIARY_REVIEW/BENEFICIARY_STATEMENT 종류의 append-only sorting_records를 사용하며 신규 DB 테이블/migration/의존성은 없다. 신청 revision+BEGIN IMMEDIATE+요청키로 전체 저장·동시 편집·재전송을 통제한다. 행별 회원 귀속 합계는 예약량 이하, 비용은 같은 시설·신청의 배부액 이하 및 전체 정상 이체 후보 한도 이하여야 한다. 비용 원본 입력 해시와 귀속/비용/정상 이체 증빙 바이트를 검사한다. 비용을 연결하지 않으면 0으로 가정하지 않는다. 수동 참고액도 null과 입력한 0을 구분하고, 미확인 항목을 포함한 금액 합계는 미확인으로 남긴다.

## M1 수출이행·확인서 연결 후속 기록

신청행별 실제 수출이행 근거와 사무국 확인서 연결을 구현했다. 신규 sorting_evidence_review.py와 strict API/화면에서 부분 연결, 범위 대사, 검토 표기자·사유·시각, 요청 멱등키, 신청 revision, 과거 검토 버전 및 철회를 보존한다. 원장 기재 선적일은 수정하거나 실제 수출일로 복사하지 않는다. AWB/B/L 보조자료만으로 실제 수출일을 기록하지 않는다.
