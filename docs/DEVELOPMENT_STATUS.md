# 개발 현황 및 인수검사

제공된 9종 기존 Excel과 2027년 공식 제출양식을 분석했습니다. 샘플 자료는 원래 위치에 보존했습니다. 합성 데이터로 회원사 등록, 중복 검증, 신고 입력, 자격 판정, 실행번호 조회, 양식 출력, 감사 보고서 및 백업 복원을 검증합니다.

| 단계 | 구현 범위 |
| --- | --- |
| 0–1 | 기존 양식 분석, 한국어 10개 메뉴, FastAPI·React·SQLite·Alembic 초기 구성 |
| 2–3 | 명부 및 원장 등록·수정, 원장 논리 제외, 가져오기와 다운로드, 항목 단위 서버 검증, 사용자 열 매핑 |
| 4–5 | Decimal 계산, 중복 품목란 검증, 정책과 실행 이력, 회원별 집계 및 증빙 조회 |
| 6–7 | 공식 제출양식, 확정 스냅샷, 변경이력, 감사 Excel·ZIP, DB 백업 |
| 8 | Windows 실행 패키지 빌드, 배포 스크립트와 운영 문서 |

## 시험 결과

- pytest 18건 통과. 6개 귀속 예시, 중복 및 정정 충돌, 공식 양식 셀·병합 대사, 수식 주입 방지, 백업 복원 포함.
- Vitest 2건 통과. 탭 구분 붙여넣기에서 빈 셀과 선행 0 보존 및 범위를 초과한 열 검증.
- Playwright Microsoft Edge에서 조직 등록, 회원사 입력, 중복 오류 표시, 명부 다운로드 시나리오 통과. 소스 실행과 별도 DB를 사용하는 Windows 실행 파일에서 각각 검증했습니다.
- 기존 9개 파일에서 총 11,280행을 시험 DB로 가져와 조직별 계산 검증까지 13.86초. 필수 증빙이 빠진 행은 인정 원장에 반영되지 않았습니다.
- 합성 데이터 계산 엔진 실행에서 10,000행 1.53초, 50,000행 7.59초. 웹 전송, 원장 저장, 화면 렌더링 시간은 별도입니다.

## 남은 항목

- 원장 셀 직접 편집, 다중 선택과 범위 복사, 자동 저장, 전체 오류 위치 강조, 오류 해결 승인 이력, 재사용 열 매핑 및 세밀한 필터.
- 전체 M/D 코드, 품목별 단가 이상치와 단위 환산, 정정본 적용 범위 승인, 근거 있는 예외 승인, 복수 개정 자동 대사. 음수·정정 충돌은 검증 보류 상태입니다.
- 사업자 별칭·신고 헤더/역할·검증/해결·자격/귀속을 독립 테이블로 분리, 관리자 인증, 담당자 역할별 권한, 파일·필드 암호화, PostgreSQL 연결.
- 전용 복원 UI, 원본 파일 선택 포함 ZIP, 확정 전후 비교와 템플릿의 복합 수식 검증, 모든 제공 파일에 대한 실제 확정 인수시험.
- 50,000행 부하 측정은 계산 엔진 기준입니다. 업로드부터 브라우저 표시까지의 전 구간 부하 시험과 별도 Windows PC 검증이 필요합니다.

실제 제출에는 조직 담당자의 기준일, 귀속일, 대상 HS코드 확인과 실제 신고필증·회원명부 대사가 필요합니다.
