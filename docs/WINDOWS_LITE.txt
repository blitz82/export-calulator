공동정산 수출실적 관리 Windows x64 경량판

1. GitHub 공식 릴리스에서 받은 ZIP을 우클릭하고 속성 → 일반을 엽니다. 하단에 차단 해제가 표시되면 체크하고 적용을 누릅니다.
2. ZIP 전체를 쓰기 가능한 로컬 폴더에 풉니다.
3. Start-EPMS-OCR.cmd를 실행합니다. _internal 폴더도 함께 보관합니다.
4. WebView2 설치 안내가 나오면 Microsoft 다운로드 페이지에서 Evergreen Bootstrapper 또는 x64 독립 실행형 설치 파일을 설치하고 프로그램을 다시 실행합니다.
   https://developer.microsoft.com/microsoft-edge/webview2/#download

이미 압축을 푼 뒤 Python.Runtime.Loader.Initialize 또는 Python.Runtime.dll 오류가 나오면 원본 ZIP의 차단을 해제한 뒤 새 로컬 폴더에 다시 풉니다. 기존 폴더에 업무 자료가 있다면 보관하세요.

기존 자료를 가져오려면 먼저 기존 프로그램에서 백업을 내려받습니다. 두 프로그램을 닫고 기존 실행 파일 옆의 data 폴더를 새 실행 파일 옆에 복사합니다. 새 폴더에 이미 업무 자료가 있다면 덮어쓰기 전에 별도로 백업하세요.

기본 데이터는 실행 파일 옆 data\epms.db에 저장됩니다.

Start-EPMS-OCR.cmd는 Windows PowerShell에 실행 정책이 지정되지 않았을 때 이번 실행에만 RemoteSigned를 적용합니다.
