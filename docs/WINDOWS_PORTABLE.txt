공동정산 수출실적 관리 Windows x64 무설치 배포본

1. GitHub 공식 릴리스에서 받은 ZIP을 우클릭하고 속성 → 일반을 엽니다. 하단에 차단 해제가 표시되면 체크하고 적용을 누릅니다.
2. ZIP 전체를 쓰기 가능한 로컬 폴더에 풉니다.
3. 공동정산 수출실적 관리.exe를 실행합니다. 같은 폴더의 WebView2와 _internal을 함께 보관합니다.

이 배포본에는 WebView2와 Python 런타임이 포함되어 있습니다.
이미 압축을 푼 뒤 Python.Runtime.Loader.Initialize 또는 Python.Runtime.dll 오류가 나오면 원본 ZIP의 차단을 해제한 뒤 새 로컬 폴더에 다시 풉니다. 기존 폴더에 업무 자료가 있다면 보관하세요.

Windows 10에서는 첫 실행에 WebView2 폴더에만 앱 컨테이너의 읽기 및 실행 권한을 적용합니다.
프로그램을 종료하려면 프로그램 창을 닫습니다.
처음 실행하면 프로그램 설정에서 사무국의 품목명을 직접 입력합니다.
기본 데이터는 공동정산 수출실적 관리.exe 옆 data\epms.db에 저장됩니다. 같은 폴더에서 다시 실행하면 저장한 자료가 열립니다.
시작 오류 로그는 %LOCALAPPDATA%\EPMS\startup.log에서 확인할 수 있습니다.
