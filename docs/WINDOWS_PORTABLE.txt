공동정산 수출실적 관리 2.0.2 Windows x64 무설치판

1. ZIP 전체를 쓰기 가능한 새 로컬 폴더에 압축 해제합니다.
2. 프로그램 시작.exe 하나를 더블클릭합니다. 전용 프로그램 창이 열립니다.
3. _internal과 라이선스 폴더, 무설치판의 WebView2 폴더를 함께 보관합니다.

경량판은 PC에 설치된 Microsoft WebView2 Runtime을 사용합니다. 설치가 어려운 PC에서는 런타임이 포함된 무설치판을 사용하세요.
무설치판의 첫 실행에는 Microsoft WebView2 사용약관을 직접 확인한 후 선택합니다.
CMD 선택이나 브라우저 실행은 필요하지 않습니다. Python·Node.js 설치도 필요하지 않습니다.
자료는 실행 파일 옆 data\epms.db에 저장됩니다. 기존 자료는 기존 프로그램을 종료·백업한 뒤 새 폴더로 옮기세요.
종전 시험용 data\sorting-review.db와 일반 data\epms.db는 서로 다른 파일이므로 덮어쓰지 말고 확인하세요.
ZIP의 속성에 차단 해제가 표시되면 적용한 뒤 압축을 풉니다.
시작 오류 로그: %LOCALAPPDATA%\EPMS\startup.log
OCR은 Windows 인식 언어에 영향을 받으며 수동 입력할 수 있습니다.
