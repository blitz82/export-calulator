# 감사 검증

계산 실행번호를 선택하고 회원사 집계에서 인정 내역을 엽니다. 신고번호·품목란·정정 버전, 역할별 자격, 직접 우선 사유, 실제 USD와 kg를 대사합니다. 원장 ID로 계산 당시 입력값과 파일·시트·행·해시를 확인할 수 있습니다. 변경 이력은 저장 이후의 정정을 포함하므로 계산 당시 값은 실행 스냅샷을 사용합니다.

계산 검증 Excel에는 회원별 집계, 인정·제외 근거, 검증 결과, 원장 출처와 해시가 포함됩니다. 감사증빙 ZIP에는 계산 검증 Excel 및 당시 정책이 포함됩니다. 원본 파일은 로컬 DB에 보존됩니다.

확정된 실행번호와 작성 시트를 다시 선택하면 저장된 확정본을 다운로드합니다. 재계산 결과는 새 실행번호로 저장됩니다.
