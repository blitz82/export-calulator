# EPMS OCR 및 원장 변경 기록

## 1.3.3

- PDF 검토 항목을 신고 기본정보, 품목 및 실적, 업체 정보, 등록 판단 순으로 배치했다. 선택한 항목의 근거 위치로 이동하고, 입력칸 옆에서 PDF 영역을 읽어 후보를 적용할 수 있다.
- 서식 편집과 버전 관리는 OCR 서식 관리 화면에서 연다. PDF 승인 시 자동 검증하고 첫 오류 입력칸으로 이동한다.
- 직접 입력과 Excel 가져오기 후 행 편집에서 공동정산 대상과 신고 상태를 저장 직전의 등록 판단 영역에 배치했다.
- Windows x64 무설치판은 `공동정산 수출실적 관리 시작.cmd`로 실행한다. 이 CMD는 같은 폴더의 `EPMS.exe`를 시작한다.

## 1.3.1

- PDF 검토에서 사용자가 지정한 영역을 Windows OCR로 읽고, 후보를 현재 품목란의 입력 필드에 적용할 수 있다.
- 신고 정보, 품목 정보, 수치, 업체 상호와 사업자번호 등 19개 필드의 영역을 템플릿에 저장한다. 활성 스캔 템플릿은 서식이 일치하는 단일 품목 페이지의 빈 필드를 보완한다.
- 원장의 입력 검증에서 통과는 녹색, 제외는 주황색, 확정 차단은 기존 빨간색으로 표시한다.

## 1.3.0

현재 개발 변경에는 수출신고필증 전자 PDF 자동입력, 회전·CropBox 위치 표시, Windows OCR 부분 보완, 갑지·을지 품목 연결, 목록 중복 방지, 승인 전 검증, 보완 템플릿 버전 관리 및 오픈소스 정보가 포함된다.

보완 템플릿에는 SQLite 마이그레이션 `0003`이 필요하다. 최초 실행 전에 기존 버전에서 운영 DB를 백업하고 테스트 사본으로 업그레이드 동작을 확인한다.

스캔 인식은 문서 품질에 따라 미인식이 발생한다. Windows OCR 한국어 언어팩과 스크립트 실행이 허용된 운영 환경이 필요하다. 기관 정책이 실행을 제한하면 사용자 안내 후 원본을 직접 검토한다. 출처 좌표가 있는 경우 원본에서 선택값을 대조한다.

검증용 산출물에는 배포 승인과 구분되는 라이선스·취약점 검토 항목이 남아 있다. [오픈소스 검토 안내](오픈소스%20검토%20안내.md)
