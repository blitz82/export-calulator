# 계산 업무규칙

1. 해당 통합조직에서 정책 기준일에 자격이 있는 회원을 인정합니다. 생산자·수출업체·복수 회원에 같은 기준을 적용합니다.
2. 대행자와 화주는 직접, 제조자는 간접 자격을 갖습니다. 동일 사업자의 여러 직접 역할은 한 번 인정합니다. 직접과 간접을 겸하면 자격은 둘 다 기록하고 금액과 물량은 직접으로 한 번 귀속합니다.
3. 서로 다른 회원은 각각 인정합니다. 수출대행자와 수출화주의 비회원 확인은 해당 사업자의 자격에만 영향을 미칩니다. 제조자는 기준일에 회원 자격이 있는 생산자 또는 복수 회원이어야 합니다. 제조자가 확인되지 않으면 품목란 전체를 집계에서 제외합니다.
4. 통합조직 내 신고번호와 실제 품목란을 기준으로 자료를 묶습니다. 같은 정정 버전에서 입력값이 일치하면 한 건의 실수출로 집계합니다. 내용 충돌이나 여러 정정 버전의 적용 범위는 담당자가 원본을 확인합니다.
5. 정책에서 선적일 또는 신고일을 귀속연도 기준으로 지정합니다. 회원자격 기준일과 허용 HS코드도 연도별로 등록합니다. 가입승인일 포함, 탈퇴일 제외 경계를 적용했으며 운영 전에 조직 정책과 대조해야 합니다.
6. 실수출액은 유효 품목란별로 집계합니다. 회원사 귀속액은 인정받은 사업자별로 계산하므로 실제 수출액을 초과할 수 있습니다.
7. 공식 양식에는 2026-12-31 기준 회원사를 기재합니다. 확정은 현재 원장·명부·정책에 해당하는 두 실행번호와 검증 통과가 필요합니다. 운영자료에 적용할 금액 종류, 정정 승인 절차, 날짜 예외 등은 사용자 확인이 필요합니다.
