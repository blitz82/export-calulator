# EPMS 2.0.2 — 중복된 업무 시작 메뉴 정리

- 왼쪽 「업무 시작」 메뉴를 제거했습니다. 자료 등록·관리, 공동선별비 정산·제출, 회원사별 수출실적으로 직접 이동합니다.
- 실행 첫 화면은 「업무 안내」입니다. 간단한 안내와 기존 메뉴 바로가기만 제공하며 별도 작업을 생성하지 않습니다.
- 첫 안내 화면을 월별 정산 컴포넌트에서 분리해 불필요한 정산 현황 조회를 하지 않습니다.
- 월별 진행 현황, 이어서 처리하기, 보완할 자료, 사무국 기본정보는 「공동선별비 정산·제출」에 그대로 유지합니다.
- 기존 데이터, 계약 검증, 수출실적 계산과 공동선별비 계산 규칙은 변경하지 않았습니다.

## 다운로드 후 실행

Windows x64용입니다. ZIP 전체를 새 쓰기 가능한 로컬 폴더에 풀고 `프로그램 시작.exe` 하나를 실행하세요. 두 배포본 모두 CMD와 브라우저 대체 실행 없이 PC 전용 창으로 열립니다.

- 경량판: PC에 설치된 Microsoft WebView2 Runtime을 사용합니다.
- 무설치판: WebView2를 포함합니다. 첫 실행의 사용약관은 직접 확인 후 선택하세요.
- Python·Node.js 설치는 필요하지 않습니다. `_internal`, 라이선스, 무설치판의 `WebView2` 폴더를 함께 보관하세요.
- 데이터는 실행 파일 옆 `data/epms.db`에 저장합니다. 기존 프로그램을 종료하고 백업한 뒤 새 폴더로 데이터를 이전하세요. 운영 DB를 덮어쓰지 마세요.
- 종전 시험용 `data/sorting-review.db`는 일반 DB와 다릅니다. 사용할 자료를 확인·백업한 후 이전하세요.
- OCR은 Windows에 설치된 인식 언어에 영향을 받으며, 실패 시 직접 입력할 수 있습니다.

공개 소스·배포 ZIP에 운영 데이터나 시험 데이터는 포함하지 않습니다.
