# EPMS 2.0.3 — 감수 결과를 반영한 업무 사용성 보완

- 수출 최종 확정에는 실제 거래 날짜에 유효하고 원문 검토가 **확인 완료**인 계약 및 지정된 원문 근거가 필요합니다. 미검토·확인 필요 계약도 입력 보관은 가능하지만 최종 확정에는 사용할 수 없습니다. 자기 수출 예외는 유지합니다.
- 기존 미검토 계약을 자동 승인하지 않습니다. 계약서 등록에서 실제 PDF를 확인하고 근거를 지정한 후 확인 완료로 저장하세요. 과거 보존된 확정본은 소급 수정하지 않습니다.
- 선별장·계약·원장·지원기준·정산·보고의 미저장 메뉴 이동을 공통 대화상자로 보호합니다. 계속 작성, 저장하고 이동, 버리고 이동을 제공합니다. 입력 중인 선별 행은 화면에서 먼저 저장하도록 안내합니다. 지원되는 Edge/WebView2에서는 뒤로가기 이동도 보호합니다. 앱 종료는 브라우저의 기본 변경 경고를 사용합니다.
- 기본 본문과 입력은 16px, 보조 안내는 14px 중심으로 조정했습니다. 주요 버튼은 40~44px이며 대비를 높였습니다.
- 매칭은 글자가 축소되지 않는 목록을 기본으로 제공합니다. 선별기록 선택, 신고 후보 확인, 연결 조정 순서로 진행합니다. 연결도는 선택 보기이며 최소 원래 크기를 유지합니다.
- 지원액 확인 단계는 현재 작업을 유지하며 계산 기준을 엽니다. 새로고침 후에도 작업을 복원합니다.
- 회원사는 필수 4개 항목을 기본 표시하고 연락처·주소 등은 선택 상세에 둡니다. 계약 조항·약정 금액·메모도 선택 상세로 이동했습니다. 선별장 등록은 라벨이 분리된 2열 폼입니다.
- 모호한 숫자 붙여넣기를 조용히 변환하지 않고 오류를 표시합니다. 정상적인 천 단위 쉼표, 소수 정밀도, 빈 값과 0의 구분은 유지합니다.
- 월별 보고의 단일 회원사 거래는 전액 배분을 제안하며, 사용자가 직접 바꾼 배분액은 자동 덮어쓰지 않습니다. 실제 지급 확인은 별도입니다.
- 저장 버튼을 입력 누락만으로 잠그는 대신 구체적인 보완 메시지를 제공합니다. 지원기준 신규 등록 사유는 기본값을 사용하며 수정 사유는 계속 필요합니다.
- PDF·ZIP 파일명에 월·품목·문서 종류·차수/식별자를 포함합니다. 화면에 버전과 빌드 날짜를 표시합니다.
- 최초 기준정보 체크리스트와 공동선별비·연간 수출실적의 별도 업무 안내를 추가했습니다.

## 설치·데이터 보존

새 버전은 새 폴더에 풀어 실행하세요. 이전 프로그램과 운영 DB를 종료·백업한 뒤 기존 데이터 경로를 사용합니다. 소스 구조·기존 PDF·과거 확정본을 일괄 변경하는 DB 마이그레이션은 없습니다. 계약 확인 기준 강화로 기존 미검토 계약을 사용하는 **새 확정**은 차단될 수 있으므로 실제 원문을 확인해 보완하세요.

기능 검증은 격리된 합성 DB에서 수행합니다. 실제 초보 사용자 인수시험과 기관별 계약·지급 업무 기준 확인을 대체하지 않습니다.
