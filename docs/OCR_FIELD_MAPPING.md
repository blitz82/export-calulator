# 수출신고필증 필드 매핑

| 화면 필드 | 원본 근거 | 처리 단위 |
| --- | --- | --- |
| 신고번호·신고일자 | 상단 신고번호·신고일자 라벨과 인접 값 | 신고서 |
| 수리일자 | 신고수리일자 라벨과 날짜 | 신고서 |
| 대행자·화주·제조자 상호 | 각 역할의 라벨 인근에서 얻은 유일한 문자열 | 신고서 |
| 화주 사업자등록번호 | 수출화주 블록의 사업자등록번호 라벨 | 신고서 |
| 품목란 번호 | 란번호/총란수의 왼쪽 값. 우측 총란수는 범위 검증에 사용 | 품목란 |
| HS코드·순중량·품목별 FOB | 각 품목란 블록의 세번부호, kg 단위 순중량, USD 표시 신고가격 | 품목란 |
| 일련번호 | 일련번호 라벨이 명시한 값. 현재 검토 화면에 표시 | 원본의 일련번호 |

일련번호, 문자열 형태의 품목란 번호, 총란수, 품목 내부 세부행 번호, 정정 버전과 페이지 번호는 각각 별도의 의미를 가진다. 번호 인식에 실패한 품목도 명시된 필드의 검토 후보를 유지한다. 문서 전체 총중량과 총신고가격은 개별 품목 블록의 경계로 사용한다.

대행자·제조자 사업자등록번호, 목적국, 선적일, 정정 차수, 모델·규격은 해당 필드의 자동 추출과 근거 매핑을 추가 검증해야 한다.
