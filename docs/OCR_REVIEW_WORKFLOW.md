# PHASE 7 OCR 검토와 고급 템플릿 설정

## 신고필증 검토

신고 원장에서 PDF를 올리면 오른쪽 상단에서 신고번호, 검토 품목란, 원본 쪽을 확인할 수 있다. 오른쪽은 신고 기본정보, 품목 및 실적, 업체 정보, 등록 판단 순으로 표시한다. 항목을 선택하면 입력칸이 열리고, 좌표가 있는 경우 왼쪽 PDF에서 근거 위치를 보여 준다. **다음 확인 항목**으로 비어 있는 필수값, 원본 확인이 필요한 수치, 값 불일치 및 검증 오류를 확인한다. FOB·순중량의 원본 확인은 값을 수정하면 해제된다.

원본 미리보기에서 확대, 이동, 90도 회전이 가능하다. 저장된 근거 위치는 회전한 화면에도 맞춰 표시한다. 입력칸 옆 **PDF에서 읽기**를 누르고 PDF에서 값을 드래그한다. 후보를 원본과 대조한 뒤 **후보 사용**을 누르거나 직접 입력한다. **승인하고 원장에 등록**을 누르면 등록 전에 검증하며, 오류가 있으면 첫 오류 입력칸을 연다. 여러 품목란에 오류가 있으면 **다음 오류 품목란**으로 이동할 수 있다.

## 보완 템플릿

PDF를 연 상태에서 **OCR 서식 관리**를 연다. 원본 영역을 지정한 뒤 필드를 선택해 영역에 추가한다. JSON은 **서식 백업 및 이전**에서 편집한다. 저장할 때마다 별도 버전이 생성된다. 현재 페이지에서 미리보기를 실행해 모든 지정 필드에 유일한 후보가 나오고 원본과 맞는지 확인한 다음 활성화한다. 검증을 통과한 과거 버전의 재활성화와 기본 템플릿 복원이 가능하다. 미승인 PDF는 다시 업로드할 때 활성 버전을 적용한다.

설정의 `box`는 `[left, top, right, bottom]` 순서의 정규화 좌표이다. 전자 PDF용 템플릿에서 `anchor`를 지정하면 해당 문구의 좌상단을 기준으로 한 상대값을 사용한다. 상대 좌표는 음수를 허용하지만 해석 결과가 페이지를 벗어나면 후보를 만들지 않는다. `format`은 생략하거나 `default`, `date-separated`, `date-compact`, `hs-compact` 중 해당 필드와 호환되는 값을 사용한다. 템플릿 JSON은 8KB, 필드는 최대 19개이고, `anchor`는 40자로 제한된다.

보완 템플릿은 서식이 일치하며 품목 하나를 인식한 페이지에서 지정한 필드의 빈 값을 채운다. 전자 PDF 템플릿은 기존 문자층을, 스캔 PDF 템플릿은 지정한 사각형의 Windows OCR을 사용한다. [지원 필드와 템플릿 설정 안내](OCR_TEMPLATE_GUIDE.md)

## 검증

합성 PDF와 실제 API로 초안 저장, 미리보기 이전 활성화 거절, 미리보기 통과, 활성화, 같은 미승인 PDF 재업로드 시 선적일 보완, 회전 PNG 표시와 기본 설정 복원을 확인했다. 초과 JSON 차단과 품목별 범위도 검증했다. 이전 스키마 `0002`의 테스트 DB 사본을 `0003`으로 올려 원장 행 수가 유지됨을 확인했다. 실제 기관 운영 DB 사본의 인수시험은 남아 있다.

임시 PowerShell 세션에서 합성 PDF의 영역 OCR을 실제 실행했다. 신고일자, 순중량, FOB 문자는 기대값과 같았다. 신고번호는 마지막 ASCII X를 호환 문자 Ⅹ로 읽었고 원문 후보를 그대로 표시했다. 재인식 결과를 기존 입력값에 자동 덮어쓰지 않는 동작은 브라우저 시험에서 확인했다.
