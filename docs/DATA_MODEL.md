# 데이터 모델

| 테이블 | 저장 내용 및 키 |
| --- | --- |
| organizations | 통합조직 ID 및 이름 |
| companies | 정규화된 사업자번호 기본키 |
| memberships | 통합조직별 회원관계, 사업자번호, 개정번호, 명부 데이터 |
| import_files | 통합조직·자료종류·SHA-256 고유키, 원본 파일 바이트 |
| import_rows | 파일 참조, 시트와 행, 가져온 열의 값 |
| declaration_lines | 원장 행, 자료 출처, 개정번호, 논리 제외 상태 |
| rule_sets | 통합조직·연도별 기준일, 귀속일 기준, 대상 HS코드 |
| calculation_runs | 실행번호, 원장·회원 명부·정책 및 자격·귀속·검증 결과 |
| submission_snapshots | 두 연도 실행번호와 작성 시트, 확정본 파일 |
| audit_logs | 대상, 이전·이후 값, 사용자, 일시, 변경 사유 |

신고 헤더·역할, 회원 별칭, 검증과 귀속결과 일부는 현재 JSON 필드에 저장합니다. 별도 관계형 테이블로 옮기는 작업이 남아 있습니다. 파일 및 행의 원본은 원장에서 행을 제외한 뒤에도 보존됩니다.
