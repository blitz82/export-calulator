# 사용자 매뉴얼

1. 처음 실행하면 품목명을 입력하고 **품목 등록**을 누릅니다. 등록이 끝나면 **회원사 등록하기**를 선택합니다. 다음 실행부터는 **업무 홈**에서 지금 할 일을 확인합니다.
2. **회원사 명부**에서 **회원사 추가**를 누르거나 **Excel 가져오기·내보내기**를 사용합니다. 오류가 표시된 입력칸은 바로 아래 안내에 따라 수정합니다.
3. **신고 원장**에서 **PDF에서 가져오기**, **Excel에서 가져오기**, **직접 입력** 중 가진 자료에 맞는 방법을 선택합니다.
4. 업무 홈의 **보완 필요 원장 행**을 열면 입력 검증에 걸린 행만 표시됩니다. 행을 선택하면 편집 화면이 열립니다. **다음 오류로 이동**을 누르면 보완할 입력칸으로 이동합니다. 수출대행자와 수출화주는 원본에 정보가 없으면 **원본에 없음**, 비회원이면 업체명을 입력하고 **회원사 아님**을 선택합니다. 다른 쪽이 명부에서 회원사로 확인되면 비회원의 사업자번호를 비워 둘 수 있습니다. 제조자 정보가 비어 있거나 명부에서 확인되지 않으면 **생산자 회원사 선택**에서 해당 업체를 선택합니다.
5. **설정·관리 → 프로그램 설정**에서 실적 연도별로 회원자격 기준일, 귀속일 기준, 대상 HS코드 및 근거를 저장합니다. 전년도 귀속 기준과 HS코드를 불러올 수 있습니다. 올해 회원자격 기준일과 근거는 해당 연도 사업계획을 확인해 입력합니다.
6. **제출자료**에서 실적 연도를 선택합니다. 현재 자료에 맞는 계산 결과가 없으면 **현재 자료 검토**를 누릅니다. 보완할 건의 **수정하기**를 눌러 해당 회원사 또는 신고 행을 수정합니다.
7. 두 연도의 회원사별 실적을 확인한 뒤 **최종 확정 후 제출용 Excel 다운로드**를 누릅니다. 확정 이후 자료가 바뀌면 현재 자료를 다시 검토합니다. 지난 확정본은 **보관된 확정본**에서 내려받을 수 있습니다.
8. 감사 자료, 상세 검증 이력 및 DB 백업은 **설정·관리**에서 찾을 수 있습니다.

신고 원장에서는 신고번호, 정책이 지정한 귀속 날짜, HS코드, USD 금액, 신고·대상 상태, 사업자 역할을 확인합니다. 일반 추가 화면에서는 품목란 번호와 정정 버전에 기본값 1을 사용합니다. 한 신고에 품목란이 여러 개이거나 정정 신고라면 **여러 품목란 또는 정정 신고인 경우**를 눌러 원본 값을 입력하세요. 계산에서 누락 오류가 나오면 **수정하기**를 누르세요. 품목란이 하나인 최초 신고라면 **비어 있는 항목에 1 넣기**를 누른 뒤 저장하고 다시 계산합니다. 품명·순중량·FOB·수리일·수출국·수량은 **선택 참고 항목**에 있습니다. 순중량을 비워 두어도 USD를 계산합니다.

**설정·관리 → 프로그램 설정**에서 백업 파일을 내려받은 뒤 **신고 원장 전체 삭제**를 펼치고 `모두리셋`을 정확히 입력하면 현재 통합조직의 활성 원장 전체를 비웁니다. 검색이나 필터가 적용되어도 전체에 적용됩니다. 원본 파일, 계산 이력과 확정본은 보존되고 초기화는 감사 이력에 기록됩니다.
