# 사용자 매뉴얼

1. 처음 실행하면 품목명을 입력하고 **품목 등록**을 누릅니다. 등록이 끝나면 **회원사 등록하기**를 선택합니다. 다음 실행부터는 **업무 홈**에서 지금 할 일을 확인합니다.
2. **자료 입력 → 회원사 등록·수정**에서 **회원사 추가**를 누르거나 **Excel 가져오기·내보내기**를 사용합니다. 오류가 표시된 입력칸은 바로 아래 안내에 따라 수정합니다.
3. **자료 입력 → 수출신고필증 입력·수정**에서 **신고필증 추가**를 누르거나 표준 Excel 양식을 작성해 업로드합니다.
4. 업무 홈의 **보완 필요 원장 행**을 열면 입력 검증에 걸린 행만 표시됩니다. 행을 선택하면 편집 화면이 열립니다. **다음 오류로 이동**을 누르면 보완할 입력칸으로 이동합니다. 원본에 역할 정보가 없으면 **원본에 없음**을 선택합니다. 비회원은 업체명과 사업자번호를 입력한 뒤 **회원사 아님**을 선택합니다.
5. **설정·관리 → 프로그램 설정**에서 실적 연도별로 회원자격 기준일, 귀속일 기준, 대상 HS코드 및 근거를 저장합니다. **수출실적 계산**에서 연도를 선택해 계산하고, 검증 결과에 따라 원장을 보완한 후 다시 계산합니다.
6. **회원사별 실적 확인**에서 확인할 회원사의 **보기**를 눌러 신고 품목란별 인정 내역을 확인합니다.
7. **제출자료 준비**에서 실적 연도를 선택한 뒤 **두 연도 계산**을 누릅니다. 선택 연도와 직전 연도의 계산 정책을 각각 등록해야 합니다. 검증을 통과하면 **최종 확정 후 제출용 Excel 다운로드**를 누릅니다.
8. 감사 자료, 상세 검증 이력 및 DB 백업은 **설정·관리**에서 찾을 수 있습니다.

신고 원장에서는 신고번호, 정책이 지정한 귀속 날짜, HS코드, USD 금액, 신고·대상 상태, 사업자 역할을 확인합니다. 일반 추가 화면에서는 품목란 번호와 정정 버전에 기본값 1을 사용합니다. 한 신고에 품목란이 여러 개이거나 정정 신고라면 **여러 품목란 또는 정정 신고인 경우**를 눌러 원본 값을 입력하세요. 계산에서 누락 오류가 나오면 **신고 행 열기**를 누르세요. 품목란이 하나인 최초 신고라면 **비어 있는 항목에 1 넣기**를 누른 뒤 저장하고 다시 계산합니다. 품명·순중량·FOB·수리일·수출국·수량은 **선택 참고 항목**에 있습니다. 순중량을 비워 두면 USD는 계산하고 관련 중량 합계는 미집계로 표시합니다.

**전체 삭제**를 누르고 `모두리셋`을 정확히 입력하면 현재 통합조직의 활성 원장 전체를 비웁니다. 검색이나 필터가 적용되어도 전체에 적용됩니다. 원본 파일, 계산 이력과 확정본은 보존되고 초기화는 감사 이력에 기록됩니다.
