# 공동선별비 지원기준·배정

왼쪽의 `공동선별비 지원기준·배정`에서 사업연도별 기준과 생산자회원사별 배정액을 관리합니다. 회원사 명부의 내부 식별자로 연결하며 화면에는 회원사명과 사업자등록번호를 표시합니다. 기존 수출실적 계산 규칙은 변경하지 않습니다.

## 업무 순서

1. 사업연도와 적용 기간, 총 지원예산, kg당 단가, 산식, 반올림과 중량 차이 허용 기준을 입력합니다. 단가가 최종 지원단가인지, 보조율을 적용할 원가 단가인지 구분합니다.
2. 생산자회원사별 원화 배정액을 입력합니다. 빈칸은 미배정, 0은 명시적 배정액 0원입니다. 배정합계는 총예산을 초과할 수 없습니다.
3. 근거와 변경 사유를 남기고 저장합니다. 확정된 정책이 없으면 `가정값`으로 유지합니다. 이 경우 결과는 참고 계산입니다.
4. 기존 확정 건이 있으면 예산·사용 현황에서 반영 또는 제외를 명시적으로 검토합니다. 자동으로 새 예산에 편입하지 않습니다. 반영 시 과거 계산액을 어느 회원사에 귀속할지 확인합니다.
5. 연결 화면에서 `지원기준·배정액 확인`을 누른 뒤 회원사별 계산액, 한도 적용액과 미지원액을 확인하고 확정합니다.

## 계산과 잔액

- 배정 귀속은 선별기록의 생산자회원사입니다. 여러 선별장과 정산에서 사용해도 같은 회원사의 연간 한도를 공유합니다.
- 실비 한도 산식은 비용 총액을 생산자별로 명시적으로 배분해야 합니다. 생산자마다 같은 비용 총액을 반복 적용하지 않습니다.
- 정수 원 단위 배분에서 생기는 차이는 소수 잔여가 큰 순서로 배분합니다. 총액과 회원사별 합계가 일치합니다.
- 회원사 한도를 넘는 금액은 미지원액으로 별도 표시합니다. 미지원액이 생겨도 이미 확정한 연결 물량을 다시 사용 가능한 물량으로 돌리지 않습니다.
- 추가 배정 후에는 기존 작업을 열어 새 기준을 확인하고 재확정합니다. 기존 금액을 대체하며 이전 금액과 증감액을 표시합니다. 같은 물량으로 새 작업을 만들지 않습니다.
- 사용액은 시스템에서 확정한 지원 계산액이며 실제 계좌 지급액을 의미하지 않습니다. 확정 해제 시 물량·비용 사용과 예산 사용이 함께 해제됩니다.
- 사용액보다 낮게 총예산이나 회원사 배정액을 줄일 수 없습니다. 사용 중인 기준을 비활성화할 수 없으며, 동시 저장과 확정은 서버에서 재검증합니다.

## 보존과 실행

기준 변경 사유와 전후 값, 예산 반영·제외 이력을 보존합니다. 확정 결과에는 당시 기준과 배정 계산을 저장하고 PDF에 표시합니다. 과거 PDF를 덮어쓰지 않습니다. 기존 백업·복원에 DB 테이블과 PDF 저장소가 함께 포함됩니다.

DB 마이그레이션 `0008_support_budget`은 새 테이블 두 개를 추가하며 기존 정산을 자동 편입하지 않습니다. 운영 DB에 예시 데이터를 넣지 않습니다.

소스 실행은 기존 `launch.py --no-browser --port 8765 --db <DB경로>` 방식을 사용합니다. 웹 빌드는 `npm run build`, Windows Lite 패키징은 필요한 Python 의존성을 준비한 뒤 `./package.ps1 -Python <python.exe> -Lite -OutputRoot <새 출력경로>`로 실행합니다. Lite 실행파일은 시스템의 웹 표시 환경을 사용합니다.
