# 월별 업무 중심 사용 안내

## 시작과 메뉴

왼쪽 기본 메뉴는 이번 달 업무 / 회원사별 수출실적 / 기준정보·연도 설정 / 제출자료 보관함입니다. 기존 회원사·계약·시설·신고·정산 화면과 확정 자료는 유지됩니다.

`이번 달 업무`에서 보고 작업월을 선택합니다. 같은 통합조직에서는 새 선별 접수·정산·지급보고의 제목과 대상 기간에 재사용합니다. 기존 기록의 실제 선별·선적·지급일은 바꾸지 않습니다. 다른 월의 과거 자료는 원래 날짜와 보고연월을 확인하세요.

처음 한 번 사무국 기본 작성자와 제출 지역본부를 저장하면 새 보고서에서 불러옵니다. 회원사·계약·연도별 기준은 기본 메뉴를 통해 관리하며, 월별로 다시 입력하지 않습니다. 작업월 변경 또는 다른 업무로 이동할 때 저장하지 않은 입력이 있으면 확인합니다.

## 월별 업무

1. 자료 접수: 선별장을 직접 선택하고 PDF 여러 개를 접수합니다. 선별기록·수출물량과 비용 증빙을 원문과 대조합니다.
2. 원문·회원사 확인: 신고필증의 제조자·수출업체, 계약 및 회원사 자격을 확인합니다. OCR은 입력 후보이며 자동 확정하지 않습니다.
3. 물량 연결: 개별 선 연결 또는 `여러 선별기록의 연결 후보를 한 번에 검토`를 사용합니다. 일괄 제안은 생산자·기간·검증 상태·양쪽 잔량과 원집계 공통 한도를 확인하고 날짜가 가까운 신고부터 제안합니다. 제안 표를 검토한 뒤 반영하고 서버 계산을 확인하세요. 제안 자체는 지원 적격 확정이 아닙니다.
4. 지원액 확인: 중앙 지원기준과 회원사 배정액을 확인하고 계산을 확정합니다. 물량 잔량과 미지원 금액은 구분합니다.
5. 지급 내역 등록: 내부 업무시스템에서 실제 결재·송금을 처리한 후 그 명세와 PDF 증빙을 이 프로그램에 등록합니다. 계산액을 실제 지급액으로 자동 확정하지 않습니다.
6. 제출자료 생성: 차이·증빙 점검을 통과하면 통합 PDF와 원본 ZIP을 보존합니다. 실제 제출 후 제출일·방법·접수 증빙은 별도로 기록합니다.

남은 물량은 다음 신고나 다음 작업에서 사용할 수 있습니다. 모든 잔량을 0으로 만들기 위해 억지로 연결하지 않습니다. 홈의 등록·연결·확정·보존 상태는 참고 현황이며 미지급이나 참고 계산을 실제 지급 완료로 표시하지 않습니다.

## 지급 명세 가져오기

월별 보고의 회원사별 검토·지급 탭에서 내부 시스템 지급 명세 Excel(.xlsx) 또는 CSV를 등록합니다. 첫 시트·첫 행 열 제목을 사용하며 10MB, 40열, 2000행 이내입니다. UTF-8/CP949 CSV를 지원합니다.

- 사업자번호, 회원사명, 지급일, 거래 고유번호, 실제 수취인, 지급·반환 금액의 열을 대응시킵니다.
- 대응을 기억해 두면 열 제목이 완전히 같은 다음 파일에서만 재사용합니다. 형식이 달라지면 새로 확인합니다.
- 일부 사업·회원사만 보고하려면 가져올 원본 행을 선택합니다. 빈 행이 있어도 실제 원본 행 번호를 보존합니다.
- 사업자번호가 일치하지 않으면 자동 연결하지 않습니다. 업체명 후보를 참고해 회원사를 직접 선택합니다.
- 날짜·거래번호·수취인·금액이 비어 있으면 원본 행 수동 보완에서 확인한 값을 입력한 뒤 다시 점검합니다.
- 같은 거래번호·일자·지급/반환 구분의 여러 행은 거래 한 건의 회원사별 배분으로 묶습니다. 서로 다른 거래라면 원문 기준 고유번호로 구분합니다.
- 지급 증빙 PDF를 직접 선택하고 원문 대조 확인 후 후보를 반영합니다. 가져오기만으로 지급 완료·정산 확정이 되지 않습니다.
- 원본 명세 파일은 DB 백업과 최종 원본 ZIP의 지급명세 폴더에 포함됩니다. 수정한 후보와 원본을 대조할 수 있습니다.

음수 금액은 반환 후보로 표시합니다. 과거 지급의 반환은 원 보고 정정본에서 원 지급과 함께 기록합니다. 다른 보고·동일 원본 행·동일 거래의 중복은 계속 점검합니다. 임의로 다른 거래번호를 붙인 동일 거래까지 자동 식별하는 기능은 아니므로 원문 대조가 필요합니다.

## 연도별·기간별 지원기준

연도 전체의 기본 단가·예산·회원사 한도를 우선 설정합니다. 단가가 연도 중 변경되면 `연도 중 단가 변경·기간별 적용 설정`에서 시행 기간·단가·보조율과 적용 날짜 기준을 입력합니다. 선별기간 / 선별시작일 / 선적일 / 신고일 중 실제 사업기준에 맞는 것을 선택합니다.

기간이 겹치거나 기준일이 없는 연결은 확정되지 않습니다. 서로 다른 단가 기간의 연결을 한 정산에 섞거나 원 기록이 변경일을 걸치면 원문에 근거해 기간별 기록·정산으로 나누세요. 같은 보고월에 여러 정산을 함께 포함할 수 있습니다. 총예산과 회원사별 한도는 기간별로 새로 생기지 않고 연간 공유합니다.

새 기준을 저장해도 과거 확정 계산과 PDF는 바뀌지 않습니다. 작성 중 작업은 최신 기준을 다시 확인하고, 소급 변경은 영향 검토 후 정정으로 처리합니다. 공식 기준이 미정이면 가정값·참고 계산 표시를 유지합니다.

## 증빙과 입력 최소화

근거 추가는 첫 PDF를 자동 선택하지 않습니다. 해당 PDF와 실제 근거 페이지를 직접 선택합니다. 파일 해시·기술 식별정보는 상세에서 조회합니다.

정상적인 월별 초안 저장 사유는 자동 기록합니다. 금액 조정·미지급·수취인 차이·정정·잠금 해제 사유와 증빙은 계속 필요합니다. 보고 제목·귀속 기간 변경과 추가 메모는 필요한 경우 펼칩니다. 월별 확정 계산 불러오기는 아직 보고하지 않은 전체 계산 후보만 불러오며, 일부 보고는 보고 대상에서 직접 확인합니다.

## 보존·기존 기능과 제한

회원사별 직·간접 실적의 기존 연간 인정·제출 Excel 규칙은 유지됩니다. 이 화면의 사업월이 연간 인정 규칙을 바꾸지 않습니다. 기존 물량·예산 사용액은 새 업무 홈이나 지급 기록 때문에 다시 차감되지 않습니다.

마이그레이션 0010은 사무국 기본정보·명세 원본 테이블 2개를 추가합니다. 기간별 기준은 기존 연도별 기준 JSON에 보존되며 기존 자료에는 기본값을 적용합니다. 기존 DB 전체 백업에 새 자료도 포함됩니다.

실제 초보 직원의 현장 사용성 평가는 별도입니다. 이번 빌드에서는 격리된 합성 데이터로 업무 흐름·좁은 화면·입력 오류·중복·정정과 패키지를 검증합니다. 내부 전자결재나 은행 송금, aT 접수·승인을 자동 수행하는 기능은 아닙니다. 제출서식과 개인정보 표시 범위는 해당 사업·지역본부 요구에 맞춰 확인합니다.
