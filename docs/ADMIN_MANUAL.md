# 관리자 매뉴얼

배포 폴더 전체를 로컬 디스크에 복사한 뒤 `공동정산 수출실적 관리.exe`를 실행합니다. 무설치 배포본의 기본 데이터는 실행 파일 옆 `data/epms.db`에 저장됩니다. 공유 폴더에서 여러 PC가 SQLite 파일에 직접 접근하는 구성을 사용하지 않습니다.

정책의 회원 기준일, 귀속일, HS코드는 조직에서 근거를 확인한 뒤 등록합니다. 정책 변경 뒤 실적을 재계산합니다. 공식 제출 기준일은 2026-12-31입니다.

백업은 설정에서 DB 파일로 다운로드합니다. 복원 검증은 프로그램을 종료한 뒤 백업 파일을 새 경로에 복사하고 PowerShell에서 `& ".\공동정산 수출실적 관리.exe" --db "<복원 경로>"`로 열어 수행합니다. 기존 운영 DB를 교체할 경우 프로그램을 모두 종료하고 기존 DB 및 부속 파일을 별도 보관한 뒤 복원본을 적용합니다. 회원사 수, 원장, 최근 실행번호와 변경이력을 대조합니다.

업데이트 전에 백업을 생성하고 새 배포 폴더에서 먼저 복원 사본을 엽니다. 실행에 실패하면 `%LOCALAPPDATA%\EPMS\startup.log`를 확인합니다. Windows 10에서 쓰기 가능한 로컬 폴더에 압축을 풀면 프로그램이 배포된 WebView2 폴더에 앱 컨테이너 실행에 필요한 읽기 및 실행 권한을 설정합니다.
