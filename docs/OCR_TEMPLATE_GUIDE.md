# UNI-PASS OCR 템플릿

`epms/ocr_unipass.json`은 UNI-PASS 공통 템플릿의 ID·버전, 공식 서식 자료, 제목과 제목 변형, 상단 앵커, 품목 및 총계 경계를 관리한다. 공식 서식의 개정일은 확인이 끝날 때까지 빈 값으로 둔다.

| 제목 변형 | 전자 PDF에서 확인한 페이지 |
| --- | ---: |
| 적재 전 갑지 | 35 |
| 적재 전 을지 | 25 |
| 수출이행 갑지 | 5 |
| 수출이행 을지 | 15 |

네 변형은 현재 공통 매핑을 사용한다. 페이지 추출 응답에 템플릿 ID·버전·변형 식별자를 기록한다. 알려진 신고필증 제목과 개별 변형을 확인할 수 없는 경우 변형 상태는 `unspecified`로 기록한다. 수출신고서 제목은 신고필증으로 분류하지 않는다.

상단의 신고번호·신고일자는 라벨과 후보 값의 상대 위치를 비교한다. 품목란·HS·순중량·신고가격은 모델·규격 분량에 따라 달라질 수 있어 품목 경계와 근접 라벨을 기준으로 찾는다. 신규 서식은 실제 페이지의 원본 근거를 확인한 뒤 제목, 앵커 및 경계를 등록하고, 여러 품목과 총계가 있는 샘플로 매핑을 시험한다. 레거시 서식이나 스캔 전용 템플릿의 개별 인수시험은 남아 있다.

## 선택 영역에서 읽기와 저장

1. PDF 검토 화면에서 적용할 품목란을 고르고, 입력칸 옆 **PDF에서 읽기**를 누릅니다.
2. 왼쪽 PDF에서 값만 드래그합니다. 마우스를 놓으면 자동으로 인식합니다. 입력칸 옆의 후보를 원본과 대조하고 **후보 사용**을 누릅니다. FOB 또는 순중량 값이 바뀌면 원본 확인란을 다시 체크합니다.
3. 같은 서식에 영역을 재사용하려면 상단 **OCR 서식 관리**로 이동합니다. **원본 영역 지정**으로 값을 드래그하고 **영역 필드**를 고른 뒤 **선택 영역 추가**를 누릅니다. 템플릿 이름, 대상 서식, 인식 방식을 지정하고 **새 버전 저장** → **현재 쪽 미리보기** → **이 버전 활성화** 순서로 진행합니다.

템플릿은 신고번호, 실제 품목란번호, 정정 버전, 신고일자, 수리일자, 선적일자, HS코드, 수출국, 품명, FOB, 순중량, 수량, 수량단위, 수출대행자·수출화주·제조자의 상호와 사업자번호를 지원한다. 영역에는 값 하나만 포함하고 수량과 단위는 따로 지정한다. 사업자번호 후보는 형식과 검증 숫자를 통과해야 하며, 회원 명부 확인은 기존 검증을 거친다. 공동정산 대상, 신고 상태, 회원 확인 상태는 검토 화면에서 선택한다.

스캔 PDF 설정은 Windows OCR로 선택 영역을 읽고, 서식이 일치하며 품목 하나를 인식한 페이지의 빈 값에만 자동 적용한다. 서식이나 품목을 판별하지 못한 페이지는 원본과 후보를 직접 대조한다.

업무 품목마다 활성 템플릿은 한 버전이다. 같은 업무 DB에서 템플릿 버전이 유지되며, 다른 DB로 옮길 때는 JSON으로 내보낸 뒤 가져와 검증·활성화한다.
