# 검증 코드

ERROR는 확정을 차단합니다. WARNING은 확인이 필요한 상태로 현재 버전에서 확정을 보류합니다. INFO는 상태와 조정 근거를 기록합니다.

| 코드 | 확인 또는 수정 방법 |
| --- | --- |
| M001, M002 | 이름과 사업자등록번호를 입력합니다. |
| M003, M004, M005 | 번호 자리수·검증숫자·같은 조직 내 중복 등록을 확인합니다. |
| M008, M009, M010, M017 | 가입신청·승인·탈퇴일 형식과 순서를 확인합니다. |
| M011, M012, M013 | 회원 유형·이메일·전화번호를 확인합니다. |
| D001, D002, D003, D004 | 신고번호와 원본의 실제 품목란번호를 확인합니다. |
| D005, D006, D007, D008 | 신고일과 선적일을 원본과 대조합니다. D008은 WARNING입니다. |
| D010 | 취소 확인은 INFO, 상태 미확정은 ERROR입니다. |
| D012, D013, D014, D083 | 중복 자료의 값, 정정 버전, 필수 증빙을 확인합니다. |
| D020–D023, D025–D027 | USD와 kg의 공란·형식·0·음수 여부를 확인합니다. |
| D043, D044, D045, D047 | 역할별 사업자번호, 명부 이름·별칭, 비회원 확인을 대조합니다. |
| D048, D049 | 제조자를 생산자 또는 복수 회원으로 확인하고, 계산 기준일의 회원 자격을 확인합니다. |
| D060, D061, D067 | HS코드 10자리와 정책 대상 목록을 확인합니다. |
| D064, D065 | 공동정산 여부를 확정합니다. 명시적 제외는 INFO입니다. |
| D080 | 동일 신고번호·품목란으로 등록된 중복 행을 수정하거나 제외해야 합니다. |
| D084, D085 | 동일 사업자의 역할 조정 내역입니다. INFO입니다. |
| D081 | 같은 원본 파일을 반복 가져오는 요청을 차단합니다. |

요구사항의 나머지 검증 코드와 오류 해결 승인·보류 이력은 개발 현황 문서를 참고합니다.
