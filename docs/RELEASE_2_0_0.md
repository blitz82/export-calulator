# EPMS 2.0.0

## 주요 변경

- 상시 자료 등록, 월별 공동선별비 정산·제출, 연간 회원사별 직·간접 수출실적을 구분했습니다.
- 회원사·계약·공동선별장·연도별 지원기준은 「기준정보·설정」에서 관리합니다.
- 선별기록·증빙 등록을 PDF 접수 → 내용 입력 → 확인·저장의 3단계로 정리했습니다. 임시 저장, 생산자별 물량 카드, PDF 근거 페이지 지정, 급여·지급증빙 등록을 지원합니다.
- 선별기록과 수출신고필증 카드는 날짜순으로 고정하고, 연결 상태·잔량·점검 상태를 선과 점의 색상으로 표시합니다.
- 공동선별비 연결 여부는 기존 직·간접 수출실적을 줄이거나 제외하는 조건으로 사용하지 않습니다.
- 지원단가·회원사별 한도·총예산을 적용해 계산하고, 내부결정·지출결의·실제 지급과의 차이 및 증빙을 월별 PDF·ZIP에 보존합니다.

## 다운로드 후 실행

ZIP 전체를 쓰기 가능한 새 로컬 폴더에 압축 해제하세요. Python·Node.js 설치는 필요하지 않습니다.

- 경량판: `Start-EPMS-OCR.cmd`. 전용 창에는 PC의 WebView2 Runtime이 필요합니다.
- 무설치판: `공동정산 수출실적 관리 시작.cmd`. WebView2가 포함되어 있습니다. 첫 실행에는 사용약관을 직접 확인하고 선택하세요.
- 두 배포본 공통 대체 실행: `Start-EPMS-Offline-Browser.cmd`. PC의 기본 브라우저에 로컬 화면을 엽니다. 인터넷 서버에 접속하는 방식이 아닙니다.

일반 실행과 브라우저 대체 실행은 모두 실행 파일 옆 `data/epms.db`를 사용합니다. 종전 별도 시험 버튼 `Start-EPMS-Sorting-Review.cmd`는 `data/sorting-review.db`를 사용하므로 기존 시험 데이터와 혼동하지 마세요.

기존 프로그램을 종료하고 데이터 폴더를 백업한 후 새 폴더로 복사하세요. 새 버전은 기존 DB를 마이그레이션합니다. 마이그레이션 전 원본 백업을 보관하고 실행 중인 DB를 덮어쓰지 마세요.

Windows x64용입니다. 인터넷 없이 자료 입력·계산·PDF 작업을 수행할 수 있습니다. 스캔 PDF OCR은 Windows에 설치된 언어 인식 기능에 따라 달라지며 실패 시 수동 입력할 수 있습니다. 지원기준이 미정인 계산은 가정값에 따른 참고 계산이며 공식 지원 적격 판정을 대신하지 않습니다.

공개 소스와 배포 ZIP에는 운영 DB, 가상 시험 DB, 실제 업체의 입력 Excel·계약서·증빙을 포함하지 않습니다.
