공통 매핑은 A 신고번호, D 대행자, E 화주, F 제조자, I HS, J 순중량, K 신고금액, N 선적일, O 신고일입니다. G열의 단일 사업자번호는 역할별 대응이 확인될 때 입력합니다. 배 자료의 C.W.와 토마토·파프리카의 제품별 물량을 순중량으로 사용하려면 원본 단위를 확인해야 합니다.

빈 행과 정확한 합계·소계·총계 표기 행을 건너뜁니다. 병합 셀의 자식 셀은 원본에서 확인한 뒤 보완해야 합니다. 날짜 서식이 잘못 지정된 감귤 자료 일부는 보완 대상입니다. 수식 셀은 파일에 저장된 계산값을 읽습니다. 품목란번호를 임의 부여하지 않습니다.

새 양식은 프로그램에서 내려받은 표준 양식에 옮겨서 가져옵니다. 파일당 20MB, 50,000행 제한을 적용합니다.

공식 양식에는 HS코드 시트와 양식 시트 2개가 있습니다. B~K에 회원 정보, L~N에 2025년, O~Q에 2026년 실적을 작성합니다. 데이터 시작 행은 7행입니다. 예시 데이터는 출력 양식에서 비우고 선택한 시트에 현재 조직 자료를 작성합니다.
