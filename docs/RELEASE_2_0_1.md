# EPMS 2.0.1 — 전용 창 단일 실행

- 경량판·무설치판 모두 ZIP 전체를 풀고 `프로그램 시작.exe` 하나를 실행합니다.
- 브라우저 대체 실행과 시험용 CMD, 중복 시작 CMD를 배포본에서 제거했습니다. 외부 브라우저로 프로그램을 여는 실행 옵션도 제거했습니다.
- 공동선별비 기능은 기본으로 활성화되며 데이터는 `프로그램 시작.exe` 옆 `data/epms.db`에 저장됩니다.
- 기존 시작 CMD의 OCR 프로세스 설정은 EXE 내부로 옮겼습니다. 관리자·사용자의 기존 실행 정책은 변경하지 않습니다.
- 경량판 전용 창에는 설치된 Microsoft WebView2 Runtime이 필요합니다. 무설치판에는 해당 실행 환경을 포함합니다. 첫 실행의 WebView2 약관은 직접 확인 후 선택하세요.
- Python·Node.js 설치는 필요하지 않습니다. 업무 기능·계산 규칙은 2.0.0과 같습니다.

## 기존 자료 이전

기존 프로그램을 종료하고 `data` 폴더를 백업한 뒤 새 압축 해제 폴더로 복사하세요. 새 폴더의 데이터를 임의로 덮어쓰지 마세요.
종전 시험용 실행 파일로 등록한 자료는 `data/sorting-review.db`에 있을 수 있습니다. 이 경우 일반 `epms.db`와 다른 자료입니다. 두 DB를 덮어쓰거나 자동 합치지 말고 사용할 파일을 확인·백업한 뒤 이전하세요.

Windows x64용입니다. ZIP 전체를 새 쓰기 가능한 폴더에 풀고 `_internal`, `WebView2`(무설치판), 라이선스 폴더를 함께 보관하세요. Windows가 다운로드 차단을 표시하면 ZIP의 속성에서 차단 해제 후 압축을 푸세요. OCR은 Windows에 설치된 인식 언어에 따라 달라지며 실패 시 수동 입력할 수 있습니다.
