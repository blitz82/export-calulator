# OCR 좌표계와 렌더링 검증

검토 화면의 좌표는 미리보기 좌상단 원점을 기준으로 한 `[left, top, right, bottom]` 비율이다. PDFium 글자 좌표의 범위는 페이지의 표시 영역인 MediaBox와 CropBox 교차 영역으로 정규화한다. 각 변의 위치는 너비 또는 높이 대비 비율로 저장한다.

PDFium은 페이지 회전에 따라 한 줄 내 읽기 순서를 바꿀 수 있다. 텍스트와 필드 위치는 PDF의 회전을 일시적으로 해제한 상태에서 추출한다. 파싱이 끝나면 원래 회전을 복원하고, 근거 사각형을 같은 방향으로 변환한다. 예를 들어 90° 회전에서 점 `(x, y)`는 `(1-y, x)`가 된다. 원본 파일은 저장 또는 수정하지 않는다.

Windows OCR에서 각도가 0인 경우 단어 사각형을 입력 이미지의 픽셀 크기로 나눈다. 브라우저는 정규화된 위치를 퍼센트로 사용한다. 영역 재인식은 원본 미리보기와 같은 렌더링 좌표에서 사각형을 잘라 확대한다.

| 검증 | 결과 |
| --- | --- |
| PDF 0°·90°·180°·270°, 오프셋이 있는 CropBox, 렌더 배율 1과 2.5 | 추출한 사각형과 렌더링된 실제 글자 경계 대조 통과 |
| 합성 UNI-PASS PDF, 변경한 CropBox, 네 가지 회전 | 신고번호·신고일자·란번호·HS·kg·USD 값 및 미리보기 위치 확인 |
| 270° PDF의 영역 재인식 입력 | 잘라낸 이미지에 목표 글자가 포함됐음을 확인. OCR 실행은 모의 응답으로 대체 |

스캔 기울기 각도가 0이 아닌 Windows OCR의 위치 보정과 실제 OCR 재인식은 미검증이다. invoice2data는 현재 런타임에 포함되지 않아 DPI 기반 area 좌표 변환을 적용하지 않았다.
